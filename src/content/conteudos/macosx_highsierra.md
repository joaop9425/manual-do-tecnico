# OCLP

1. Esse aqui já não é segredo a um bom tempo, mas pra quem não conhece:
   - [Open Core Legacy Patcher](https://dortania.github.io/OpenCore-Legacy-Patcher/).
2. Verifique a compatibilidade do sistema com o seu equipamento.
3. Conheça os riscos, seja livre.

## Ferramentas Necessárias

- Pendrive 16Gb+
- Internet

## Procedimento

1. **Conhecimentos de atalhos**:
`Todos os comandos a seguir pressupõe que seu mac esteja desligado, e a partir do momento que você clicar no botão de ligar, já vai apertar a sequencia de teclas e aguardar até a maçã aparecer na tela`
   - Cmd + R: Busca a versão mais antiga para o seu mac na internet
   - Option + Cmd + R = busca a versão mais recente para o seu mac na internet
(Se o seu mac roda o high sierra como versão mais recente, tem um segredinho: (Segredo)[https://mrmacintosh.com/how-to-fix-the-recovery-server-could-not-be-contacted-error-high-sierra-recovery-is-still-online-but-broken/])  
   - Option: Permite escolher de onde o boot vai ocorrer.
